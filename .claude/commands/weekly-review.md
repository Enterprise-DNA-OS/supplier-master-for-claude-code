# /weekly-review

Run `node scripts/supplier.mjs review-queue --json`, `node scripts/supplier.mjs field-conflicts --json` and `node scripts/supplier.mjs attention --json`. Read the sources and history for the highest-priority records. Report overdue reviews, source disagreements and who owns the next action. Distinguish a candidate match from a confirmed identity. Use /draft-review for the internal review pack. No messages or approvals are automatic.
