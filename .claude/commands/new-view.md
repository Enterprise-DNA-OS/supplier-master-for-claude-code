# /new-view

Read views.json and scripts/lib/render.mjs. Add a read-only query in views.json, with explicit columns and a plain title. Use the existing renderer and brand.json. Run npm run view and inspect the generated HTML on desktop and mobile. Do not add a server, forms or actions. Name the source data and any stale-record limits in the report note.
