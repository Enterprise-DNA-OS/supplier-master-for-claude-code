# Why no front end

The useful unit is a supplier record with evidence and a named reviewer. A trusted operator can inspect it, choose fields and prepare a review by asking an agent to run the CLI. Three read-only HTML reports show the queue, conflicts and approved records. There is no web application to host.

A screen can offer guided forms, visual matching, bulk review, mobile capture, shared sessions and authenticated approvals. This free base does not provide those. It also has no fuzzy matching engine, live source connector, offline mobile mode or drag-and-drop model designer. Semarchy supplies a wider data platform. Use this base for a bounded supplier stewardship process. Enterprise DNA can build the screens, permissions and connections needed for your version.

Local PGlite is for one process at a time. PostgreSQL supports a shared deployment, but the CLI still assumes trusted operators and serialises mutations. The database owner can bypass its rules. No application-level login or tenant isolation is supplied. Keep each business in a separate private database.
